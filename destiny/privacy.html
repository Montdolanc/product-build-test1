개인정보 안내

이 베타 홈페이지는 생년월일·출생시간을 서버에 저장하거나 운영자에게 전송하지 않는 정적 웹사이트입니다. 입력값은 현재 브라우저의 메모리에서만 사용하며, 페이지를 새로 고치면 초기화됩니다.

카드 PNG 저장은 브라우저 내부에서 처리합니다. 공개 공유 링크에는 수호신 ID와 공개된 기본 캐릭터 정보만 들어갑니다. 생년월일, 출생시간, 개인별 사주팔자, 개인별 상세 운세는 포함하지 않습니다.

사이트 이용 현황을 파악하기 위해 Google 태그 관리자(Google Tag Manager)를 사용합니다. 태그 관리자를 통해 실행되는 분석 도구는 쿠키 등으로 방문 페이지, 머문 시간, 유입 경로, 브라우저와 기기 종류 같은 정보를 수집할 수 있으며, 이 정보는 개인을 직접 식별하지 않는 통계로만 확인합니다. 또한 Microsoft Clarity로 클릭과 스크롤 같은 이용 행태를 분석하지만, 입력과 결과 화면은 Clarity 기록에서 가려지도록 설정했습니다. 입력한 생년월일과 출생시간은 분석 도구로 보내지 않습니다. 브라우저 설정에서 쿠키를 차단해 수집을 거부할 수 있으며, 자세한 내용은 사이트 개인정보처리방침을 참고해 주세요.

추후 회원가입, 서버 저장, AI API 등 외부 기능을 추가할 경우 별도의 개인정보 처리방침 개정과 개인정보 보호조치가 필요합니다. 정적 호스팅 사업자는 접속 로그 등을 자체적으로 처리할 수 있으므로 배포 전 사업자의 정책을 확인해 주세요.
