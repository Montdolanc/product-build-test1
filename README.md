# 오늘의 여섯 숫자

HTML, CSS, JavaScript로 만든 로또 6/45 번호 생성 실습입니다.

- 1게임 또는 5게임 생성
- 각 게임에 중복 없는 숫자 6개, 오름차순 정렬
- 다크 모드 및 브라우저 내 설정 저장
- 외부 라이브러리, API 키, 빌드 과정 없이 실행

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 번호 생성기, 생성 원리, 자주 묻는 질문, 댓글 |
| `guide.html` | 로또 6/45 가이드 (구매, 당첨금 구조, 세금, 수령) |
| `odds.html` | 등수별 확률 계산과 가상 구매 시뮬레이터 |
| `myths.html` | 로또에 관한 오해와 진실 |
| `probability-lab.html` | 조합, 연속 번호, 생일 번호의 수학적 의미를 설명하는 심층 자료 |
| `randomness.html` | 브라우저 암호학적 난수, 균등 표본 추출, 번호 빈도 해설 |
| `responsible-play.html` | 이용 비용 예시, 확률과 위험, 1336 상담 정보 |
| `destiny/methodology.html` | 출생 달력·절기·수호신 계산의 원리와 한계 |
| `about.html` | 사이트 소개, 번호 생성 원리, 문의 양식 |
| `privacy.html` | 개인정보처리방침 (광고 없음) |
| `404.html` | 없는 주소 안내 (광고 없음) |
| `styles.css`, `site.js` | 모든 페이지 공통 스타일과 스크립트 |
| `app.js`, `sim.js`, `contact.js` | 생성기·댓글, 시뮬레이터, 문의 양식 |
| `ads.txt`, `robots.txt`, `sitemap.xml` | 애드센스 판매자 정보와 검색 엔진용 파일 |

## 실행

`index.html`을 브라우저에서 열거나 `npx wrangler dev`로 로컬 서버를 띄웁니다.

## 배포

`npx wrangler deploy`로 Cloudflare Workers 정적 자산으로 배포합니다. 공개할 파일은 `.assetsignore`에 하나씩 적어야 하므로, 새 파일을 추가하면 이 목록에도 추가합니다.

애드센스 광고 스크립트는 실질적인 콘텐츠가 있는 페이지에만 넣고, 개인정보처리방침과 404 페이지에는 넣지 않습니다. 공유 카드 10종에는 `noindex,follow`가 적용되어 있습니다.

## 콘텐츠 품질 점검

`node destiny/tests/content-quality.test.js`로 교육 자료 본문 길이, 내부 링크, 한자 없는 공유 화면, 메타 정보, `ads.txt`, 검색엔진용 파일, 계산 예시를 확인할 수 있습니다. 모든 테스트는 PR 및 `main` 배포에서 GitHub Actions로 실행됩니다.

2026년 11월 14일 기준, 운영 중인 Cloudflare Pages 주소 `https://product-build-test1-1o7.pages.dev/`를 이 저장소의 대표 주소(canonical)로 사용하도록 정리했습니다. 별도 Workers 주소 또는 맞춤 도메인을 AdSense에 신청했다면, 도메인 선택과 인증 상태를 반드시 다시 확인해야 합니다. 도메인 변경은 AdSense 계정에서 확인 없이 추정해 수행하지 마세요.

구글은 AdSense 승인을 보장하지 않습니다. 아래 항목은 운영자가 AdSense 대시보드에서 직접 확인해야 합니다.
- 등록한 사이트 주소와 실제 콘텐츠의 대표 주소가 일치하는지
- 심사 신청 상태, `ads.txt` 승인 상태, 계정·결제 정보 완료 여부
- 자동 광고에서 404, 개인정보 안내, 수호신 공유 카드처럼 내용이 적은 경로가 제외되어 있는지
- 저작권, 광고 배치, 방문자 경험, 댓글 관리 및 복권 관련 제한사항이 충족되는지

인용한 동행복권·MDN·한국도박문제예방치유원 공식 페이지는 일반 정보를 확인하기 위한 외부 자료이며, 광고·제휴 계약이나 해당 기관의 보증이 아닙니다.

번호는 무작위이며 당첨을 예측하거나 당첨 확률을 높이지 않습니다.
